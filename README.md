# 선택과목

구글 스프레드시트를 읽어 보여 주는 단일 HTML 파일. 빌드도 서버도 없다.

## 데이터 경계

이 앱이 할 수 있는 일의 범위는 여기서 정해진다.

**읽기 (gviz JSONP, 7개 시트)**

| 앱 안의 이름 | 시트의 탭 이름 | gid | 쓰는 곳 |
| --- | --- | --- | --- |
| 2학년 신청 | 2학년 | 0 | 학생, 강좌 인원, 명렬표 |
| 3학년 신청 | 3학년 | 1935968761 | 학생, 강좌 인원, 명렬표 |
| 직업반 신청 | 직업반 | 469016448 | 학생(3학년 7반), 강좌 수강생, 명렬표 |
| 반별시간표 | 반별 시간표 (숨김) | 1926478023 | 학급·교사·학생 시간표, 장소 |
| 슬롯시간 | 슬롯시간매핑 (숨김) | 863995751 | 슬롯이 열리는 요일·교시 |
| 2학년 강좌표 | 2학년 교실배치 | 606989081 | 강좌의 교사·장소 |
| 3학년 강좌표 | 3학년 교실배치 | 44867740 | 강좌의 교사·장소 |

탭은 이름이 아니라 **gid** 로 읽는다. 탭 이름을 바꿔도 앱은 영향이 없다.
직업반 학생은 학번의 반 자리가 원래 반을 가리키므로(`30121` → 3-1), 시트가 알려 주는 반(3-7)으로 둔다.
강좌표의 `학생수` 는 직업반을 뺀 인원이라, 인원을 맞춰 볼 때는 직업반을 따로 빼고 비교한다.
강좌 화면의 수강생 수에는 직업반이 들어가고 `(직업반 N명 포함)` 이라고 밝힌다.

**쓰기** — 없다. (CSV 는 이 기기로 내려받는 파일이지 시트 쓰기가 아니다.)

그래서 이 앱은 뷰어다. 자료를 고치는 길은 시트를 고치고 `새로고침` 하는 것뿐이다.
쓰기처럼 보이는 기능은 두지 않는다. 명렬표 머리글 칸은 인쇄용이라 이 기기에만 남는다.

> **시트에 필터를 걸지 말 것.** gviz 는 기본 필터로 감춘 행과 숨긴 행을 아예 주지 않는다.
> 누가 신청 시트에 필터를 걸어 두면 앱은 남은 행만 받고, 그게 전부인 줄 안다.
> 걸러 보아야 한다면 `데이터 → 필터 보기`를 쓴다. 필터 보기는 개인용이라 시트 상태를 바꾸지 않는다.
> 이 함정이 조용히 지나가지 않도록 앱이 스스로 대조한다 — 아래 `덜 읽힌 자료 잡기` 참조.

## 화면

`학생` `강좌` `학급` `교사` `장소` `명렬표` — 여섯 개. 머리의 `1`–`6` 탭으로 옮긴다.

- **학생** — 학번·이름·학급·신청 과목. 눌러서 오른쪽 상세 서랍으로. 서랍에서 `‹` `›` 로 다음 학생,
  개인 시간표 인쇄. 맨 위에 조회 인원·평균 수강 과목 같은 요약 카드.
- **강좌** — 슬롯별로 묶은 강좌. 슬롯 머리에 열리는 시간과 총원. 넓은 화면에서는 두 단으로 접는다.
  슬롯 바로가기 칩, 강좌를 누르면 서랍에서 반별 분포와 수강생 명단.
- **학급** — 반 시간표와 명단. 선택과목 시간은 `이동수업 (6강좌)` 처럼 몇 개가 열리는지 적고, 누르면 그 슬롯으로.
- **교사** · **장소** · **명렬표** — 왼쪽에 목록(초성·이름 필터), 오른쪽에 선택한 항목. 교사·장소는
  주간 시간표와 담당 학급·강좌, 명렬표는 강좌를 골라 열 수·머리글을 정해 출석부를 뽑는다.

머리 검색창은 현재 화면의 목록을 거른다(초성 `ㅎㄱㄷ` 가능). 교사·장소·명렬표 왼쪽 목록은 자체 필터가 따로 있다.
표에 적힌 교사·장소·학급은 눌러서 그 화면으로 건너뛴다. 오늘 요일은 시간표 머리에 표시된다.

`Ctrl+K` 는 학생·강좌·교사·장소·학급(`2-3`)을 한 번에 찾아 바로 가는 빠른 이동 창이다.

## 동작

- **자료 출처** — 머리의 상태 칩(`정상 · 14:02` / `점검 필요 3건`)이나 맨 아래 `원본 시트 및 정합성 점검` 을 누르면
  시트별 행 수·갱신 시각·실패 사유를 적은 창이 열린다. 읽지 못한 행도 `2학년 신청 5행 · 학번 형식을 읽을 수 없습니다: 2X999`
  처럼 짚어 준다. 앱이 시트를 못 고치니, 무엇이 잘못됐는지는 알려 줘야 한다.
- **시트끼리 어긋난 곳** — 같은 창에서 시트 대조 결과도 내보인다.
  강좌표에 없는데 신청만 있는 강좌, 신청이 없는 강좌, 담당 교사가 빈 강좌,
  슬롯시간에 없는 슬롯, 같은 시간에 두 곳에 있는 교사·교실.
- **덜 읽힌 자료 잡기** — 강좌표에는 담당자가 적어 둔 `학생수` 줄이 있다. 그 값과 신청 시트에서
  직접 센 인원을 강좌마다 맞춰 본다. 어긋나면 점검 창에 적고, 학년 단위로 모자라면
  `신청 시트에서 2학년 7명이 덜 읽혔습니다` 처럼 화면 맨 위에 내건다.
  시트에 걸린 필터·숨긴 행이 여기서 드러난다. 요청은 한 건도 늘지 않는다 — 범위를 한 줄 넓힐 뿐이다.
- **신청이 빈 슬롯** — 학생이 한 슬롯을 비워 두면 그 시간이 시간표에서 통째로 빈다. 학년이 여는 슬롯과 대 보고
  `20212 박지민 — 슬롯 C 선택이 없어 …` 처럼 점검 창에 적는다. 앱이 고칠 수는 없고, 신청 시트를 고쳐야 한다.
- **반/교실** — 장소 칸에 `반/국어과교실` 처럼 적힌 수업은 그 반 교실에서 할 수도 있다는 뜻이다.
  그 반의 장소 화면에도 함께 보이고, 시간표에는 적힌 그대로 장소를 밝힌다(`반/국어과교실` 장소 화면에는 전부 모인다).
- **잃지 않기** — 강좌 목록은 강좌표와 학생 신청의 합집합이다.
  강좌표에 없는 조합도 `강좌표 없음` 으로 세워 두므로 학생이 사라지지 않는다.
- **시간 되짚기** — 강좌의 시간은 반별시간표에서 과목·슬롯·교사·장소로 맞춰 찾고,
  못 찾으면 슬롯시간으로 자리를 만들어 `추정` 이라고 밝힌다.
- **분반 합치기** — 같은 시간·같은 과목의 합반 수업은 한 칸에 `분반 1 / 분반 2` 로 모은다.
  대상반이 비어 있으면 과목·반으로 되짚는다.
- **사본 보관** — 마지막으로 받은 자료를 `localStorage` 에 둔다. 연결이 없으면 이 사본을
  보여 줘 화면이 비지 않는다. 10분마다 갱신. 점검 창에서 `기기 사본 비우기` 를 할 수 있다.
- **응답 검증** — gviz 는 권한 오류도 HTTP 200 으로 준다. `status` 와 표 구조를 직접 확인하고,
  시트가 돌려준 사유(`이 문서에 접근할 권한이 없습니다`)를 그대로 보여 준다.
- **인쇄** — A4 한 장 미리보기. 명렬표는 가로, 나머지는 세로. 글자 크기를 자동으로 정하고
  남는 세로는 행이 나눠 갖는다. 너무 작아지면 무엇을 끄면 커지는지 알려 준다. `Ctrl+P` 도 같은 결과.
- **건너뛰기** — 표와 시간표에 적힌 교사·장소·학급·슬롯은 모두 눌린다. 누르면 그 화면으로 간다.
  평소엔 그냥 글자로 두고, 손이 닿을 때만 밑줄로 드러낸다.
- **CSV** — 학생·강좌·명렬표 화면의 CSV 단추는 지금 보이는 목록(검색·학년 거른 그대로)을 엑셀용 파일로
  이 기기에 내려받는다. 시트에 쓰는 것이 아니다. 한글이 깨지지 않게 UTF-8 BOM 을 붙인다.
- **단축키** — `1`–`6` 화면, `/` 검색, `Ctrl+K` 빠른 이동, `←` `→` 학년·반(서랍에서는 이전·다음), `D` 어두운 테마, `P` 인쇄, `R` 새로고침, `S` 설정, `Esc` 검색 지우기·창 닫기.

## 시트나 시트 소유 계정이 바뀌면 고칠 곳

1. **시트 ID** — `index.html` 의 `CONFIG.SHEET_ID` (한 곳). `archive/` 의 두 파일은 맨 위 `SHEET_ID`.
   사본(`localStorage`)에 시트 ID를 같이 저장하므로, ID가 바뀌면 옛 사본은 저절로 버려진다.
2. **gid / 탭** — `CONFIG.SHEETS` 의 `gid`. 강좌표는 `lastRow`, `lastCol` 도 시트 크기에 맞춘다.
3. **Apps Script 웹앱 주소** — 이 저장소에는 없다(쓰기 없음). 나중에 쓰게 된다면 새 시트에서 다시 배포한 주소를 쓴다.
4. 시트는 **링크가 있는 누구나 보기** 로 공유돼 있어야 gviz 가 읽힌다.

## 색

슬롯 A–W 에 색상(hue)을 하나씩 주고 이웃끼리 붙지 않게 벌려 놓았다. `SLOTS` 참조.
`W2` 처럼 숫자가 붙어도 같은 시간대이므로 색은 첫 글자로 정한다.
자율활동·자습은 따로, 슬롯 없는 공통 수업은 무채색.

요소에 `--dh`(색상) `--ds`(채도)를 주면 CSS가 칩·괘선·바탕을 만든다.

> 파생 색을 `:root`에서 조립하면 안 된다. 커스텀 속성은 선언된 요소에서 값이 정해지므로
> `:root`에는 `--dh`가 없어 색이 전부 죽는다. 반드시 쓰는 자리에서 `hsl()`을 만든다.

서체는 Pretendard 하나. 웹폰트가 막히면 시스템 고딕으로 떨어진다.

## 한 줄

과목·교사·교실은 한 줄에 잇는다. 눈이 세로로 오르내리지 않고 가로로만 미끄러지게.

- 시간표 칸: `과목 교사 · 교실` 한 줄. 자리가 모자라면 뒤에서부터 줄인다(`…`).
- 강좌·담당 강좌 표: 한 행이 한 줄. 접지 않고 줄인다.
- 줄인 값은 잃지 않는다. 온전한 값은 툴팁에 있고, 눌러 들어가면 다 보인다.
- 분반 묶음(`분반 1 / 분반 2`)만은 여러 줄이 본디 모양이라 그대로 둔다.

## 시간표

화면과 인쇄가 같은 얼개를 쓴다. 칸을 요일 순서로 담고 `grid-auto-flow:column` 으로 세운다.
좁은 화면에서는 격자를 그대로 펴면 요일별 목록이 된다. 두 벌을 그리지 않는다.

## 두 판

새 판(`index.html`)과 이전 판(`archive/index-v4-minimal.html`)은 같은 시트·같은 데이터 로직을 쓰고, 화면만 다르다.
설정 창에서 서로 오갈 수 있고 설정(`sk-prefs-v1`)은 공유된다. 한 판에서 보이는 자료 문제는 다른 판에서도 같다 —
시트를 고쳐야 하는 문제다.

## 되돌리기

```bash
git revert --no-edit <배포 커밋>            # 커밋 하나로 복귀
cp archive/index-v4-minimal.html index.html # 이 개편 직전의 가벼운 판
cp archive/index-v3-legacy.html index.html  # 그 이전 운영본
```

`archive/` 의 두 파일은 그 자체로 도는 앱이라 브라우저로 바로 열어 비교할 수 있다.
저장 키가 판마다 달라(`sk-prefs-v1` / 없음) 오가도 설정이 섞이지 않는다.

## 손볼 때

`index.html` 한 파일. `<style>`은 토큰 → 조각 → 머리 → 시간표 → 명렬표 → 출처 → 창 → 인쇄 → 반응형 순,
`<script>`는 설정 → 유틸 → 상태 → 자료 → 엮기 → 사본 → 검색 → 그리기 → 상세 → 인쇄 → 조작 순.

시트를 바꾸면 `CONFIG.SHEETS`, 슬롯을 늘리면 `SLOTS`(이름·색상·채도)만 고치면 된다.
강좌표는 슬롯마다 `학생수 / 교사 / 수업장소` 세 줄이 붙어 있는 모양을 전제로 읽는다.
줄 순서가 바뀌면 `readCourses` 를 고쳐야 한다.
